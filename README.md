# Mat

Veckomeny, inköpslista och recept i en app. Flikarna har egna adresser: `#/hem` (startsidan), `#/meny`, `#/inkop`, `#/recept`, `#/installningar`.

Filer: `index.html` (appen), `recept.js` (recepten), `veckomeny.json` (menydata), `bilder/`, `sw.js`, `manifest.webmanifest`.
Lägg alla filer i roten av ett GitHub Pages-repo.

Kugghjulet i alla flikar öppnar en gemensam inställningssida: tema, GitHub (användarnamn, repo, branch, token) och sedan
Veckomeny- och Recept-specifika inställningar.
